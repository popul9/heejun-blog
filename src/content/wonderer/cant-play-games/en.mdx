Is this an occupational hazard of being a developer, or is it just me?

Building software feels like playing The Legend of Zelda: Breath of the Wild.

What's beyond that mountain? Spot a shrine on the way, go have a look. Then wander off somewhere else. What was I doing again?

I'll be driving when something occurs to me. Hang on... could I build that? Next thing I know, I'm talking it through with AI, figuring out where to start, and giving it a go. Once I've got the basic idea, actually building it is the easy part.
And if that works, couldn't I do this other thing too? And off I go down another rabbit hole.

Eventually, I come up for air. Hang on, where am I going with this? Okay, so I *can* build it. But is it worth building? Have I made it unnecessarily complicated?
Have I ended up making something that caters a little too much to my own tastes?

Then I come across some syntax I've never seen before. Oh, that's interesting. You can write code like that in .NET?
Hmm... but doesn't that make the code more complicated? Is there a clear advantage over the existing syntax?

I'm wrapped up in work as usual when it hits me. Is any of this actually worthwhile? Sure, enjoying it should be enough. But can I really run on the sheer joy of technology alone? Does all this effort make commercial sense? Does that make me, a developer, an expert at chasing things that don't pay off?

Then I start digging into UX. At this point, should I just make a game? I want players to feel like they're in control, but I can't throw so much at them that they get overwhelmed. Apparently I can use C# with Unity on a Mac too. Maybe I should try it out? Onto the TODO list it goes.

Wait, AI is getting into philosophy now too? So they're not just training it to give the "right answers" anymore? They can take the way my thoughts connect, the logic of how I get from one idea to the next, and train it on that too?? Should I start learning to bake bread, just in case? But then, isn't it only a matter of time before machines take over baking too?

Hmm...
I think I've wandered pretty deep into the woods of tech. There are just too many things besides games to get lost in.
