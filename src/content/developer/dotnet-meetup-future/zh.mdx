今年最后一场 .NET 活动，去了。在阿德莱德，要找真正深入技术的聚会，这场真的是独一档。

第一次去的时候，技术内容太深，还有点懵。不过就算听不懂，去听个两三次，也会碰到类似的主题，所以参加起来没什么压力 :)。当然，最近主要聊的都是 AI。

我尽量从用户体验出发去思考问题，而不是从技术出发（虽然我真的很喜欢技术）。（但要说我完全没有工程师本位的思维，那我也不敢认。）不过在这里，可以毫无负担地聊技术，聊亲自用过这些技术的人那些鲜活的经历。

也就是说，这场聚会最棒的地方，就是这里聚着一群真正在做工程的人。（现场居然有三位 Microsoft MVP。对我来说，真的就是，哇..）还有带领这些团队的人，以及相关的各方参与者。能有机会和这么多不同角色的人聊聊。

![在阿德莱德 .NET 聚会上听分享的参加者](./img_7611.avif)

举几个例子，

- 带领企业软件开发及咨询公司 SSW 的 Adam Cogan。
- 自由职业者
- 离开稳定的高薪工作，投身创业的人
- 做国防项目的开发者
- 学生 & 初级开发者
- 训练和开发 AI 模型的人
- 还有阿德莱德本地那些年复一年，坚持组织 .NET、DDD Adelaide 这类社区活动的组织者们。

总之，有机会认识了各种各样的人。<br/>
说真的，除了钱，还能给开发者什么比这更好的东西吗？啊，当然，免费的达美乐披萨除外。<br/>
没吃晚饭，达美乐吃得挺香，就是忘了拍照。感谢提供披萨的 Simon、Encode Talent，还有各位赞助商 😋

这次聚会，我特别留意的是，现在软件开发圈里，开发者对 AI 的看法正在发生什么变化，以及这些变化实际带来了什么影响。

确实感觉项目变多了，对人手的需求却变少了。还有，我们作为开发者/工程师，对好的设计有自己的坚持和自豪感，怎样才能把这些转化、传达成客户也能切实感受到的价值？这是我最近在琢磨的事，所以听的时候也格外留意这一点。
换句话说，在 Richard 的 [Worse is Better](https://dreamsongs.com/WorseIsBetter.html) 和 [Worse is Better is Worse](https://dreamsongs.com/Files/worse-is-worse.pdf) 之间，我也跟他一样，愉快地摇摆不定中..哈哈。

啊，还有一位软件工程师，因为 AI 带来的代码审查开销太大，正在思考它到底适不适合在实际工作中大量使用。他在分享过程中提问，和讲者 Adam Cogan 交流的那一幕，让我印象挺深。<br/>
分享结束后，我主动过去找他，又聊了挺久。我反问他，不管是编译器、JVM 和 .NET Runtime 这样的运行时环境，甚至是 CPU 在电路层面怎么实现的，我们终归都得信任它们，才能继续往下开发。说到底，软件开发者这个职业，总得在某一层相信某个黑箱，那用提示词让 AI 干活，本质上不也是一样吗？所以我想表达的是，开发者喜不喜欢用 AI 提示词来做事，或许与其说取决于 AI 的“智力”、完成任务的“能力”，不如说取决于 AI 模型能不能跟自己的工作意图对上，以及用起来心里踏不踏实。

结果没想到，他做过很多国防项目，跟我工作的环境完全是两个世界。在人命攸关、保密要求极高的环境和条件下，把正在使用的系统摸得透透的，哪怕细到在我看来有点过头，反而会是个加分项。聊完之后，我认真想了想自己的开发环境和技术栈。

- 我主要做 Web 开发。
- 我写的代码主要依赖浏览器，或者运行时。（毕竟 Java、C# 都是 Web 服务端的主流选择。神奇的 JVM、.NET Runtime，代码跑着跑着，就自动编译成机器码，连优化都一起做了。）
- 开发市场的大头是 Web，也许正因如此，从优化到帮你揪出错误的编译检查、类型检查，开发工具简直贴心得离谱。开发者就算想搞砸点什么，到处也都有安全网接着。
- 在这样的环境下，AI 模型也已经很擅长这类工作了。《钢铁侠 1》里，跟贾维斯说一声，战甲这里那里帮我弄一下，它就给你弄得刚刚好。在 Web 开发的世界里，我们早就到了这个阶段，甚至早就超过了。
- Web 开发里复杂的部分，归根结底还是数据库。我现在也经常大致看一眼代码就提交了，但至少涉及实体的改动，我会看上两三遍。再说一次，已经部署的代码可以改，但已经形成的数据结构，改起来真的很麻烦。只要数据之间的关系和结构在我脑子里画得清清楚楚，代码写得再烂，只要能编译，之后都能修（前提是没把结构搞乱）。

总之，我们聊了挺久。快结束时，聊到大学学过的东西，自然就说起毕业多久了。我知道他肯定比我有经验，但居然是二十年..!（反正我才两年）<br/>
嗯..一个第二年的开发者，来到能尽情聊 IT、聊开发经历的地方，兴奋得不行，他还这么认真地听我发表意见，突然就觉得特别感谢。

![在 .NET 聚会上介绍 DDD Adelaide 2026 活动](./img_7607.avif)

所以这次聚会的主题？寓意？对我来说，是感谢。

- 那些为开发者做开发的人，让我的代码有个能尽情撒欢的环境。更具体一点，就是到场的各位 MS MVP 贡献者。
- 为这些交流张罗聚会、提供场地的社区活动组织者。
- 还有那些不论资历，都会认真听我的感受和想法，还会追问几句的资深工程师。
- Codex，每月 20 美元，就让我能用上 AI，在开发这片森林里到处疯跑。（不只是实现代码，各种各样的好奇心，现在都能自由地去探索了。）
- 让我在工作中积累了许多体会的公司。
- 最后，还有让这些有趣对话得以发生的酒吧，West Oak Hotel。（可惜没拍照。）

前面还会有什么等着我呢？<br/>
在这里遇到的人里，谁最像未来的我呢？<br/>
很久以后，我会不会也有一双能看清全局的工程师的眼睛？<br/>
还是说，依然会在开发这片草木丛中，开开心心地，忙着解眼前的一道道谜题呢？
