前阵子我发了一篇[《UI is Hard》](/zh/developer/ui-is-hard/)，有个朋友看完之后给我发了这些。

- [r/badUIbattles](https://www.reddit.com/r/badUIbattles/)
- [Worst UI Challenge](https://worst-ui-challenge.vercel.app/)

诶，好玩。我以前只会抱怨 UI 太难，从没想过故意把它做烂（至少最近没想过）。

嗯..我这个脑子一直像条只会往前游的鱼，满脑子都是效率。那这次就让它尽可能慢下来，做一个低效的 UI 试试。

所以这篇文章算是上一篇的悖论，也是我对 Richard P. Gabriel 的 [Worse is Better is Worse](https://dreamsongs.com/Files/worse-is-worse.pdf) 的致敬：**UI is Hard is Easy**。哈哈 😆。

好，我的想法是这样的。

把橄榄球踢进圈里。越接近目标点，音量就越接近 100。

我交给 Astra（Codex）去做，大概三十分钟，几轮提示词就搞定了。拖动球来瞄准，松手就会踢出去。祝你踢得准..哈哈。

先说一下，这个不会改变你设备的音量。你可以用游戏里的 Test sound 听听结果。

今天的主题是把 UI 搞砸？是没错，但我的 UX 价值观照样适用。尽量让用户对操作拥有控制权。不要一次给太多认知负担。一次只用操心一件事。

换个说法：你控制不了的部分又多又复杂，但能控制的，我只给你一个。

## Inspiration

灵感来自今年年初我在游戏展上看到的 **Pro Jank Footy**。我之前在[这里](/zh/roamer/sage-2026/)分享过。

当时球的运动方式特别奇怪，我就问开发者是怎么做的。他说内部是 3D 引擎，玩家看到的则是蒙了一层 2D 滤镜。这件事在我脑子里转了好一阵，一直想着什么时候能用上，今天总算用上了..哈哈

![Pro Jank Footy 的 Steam 页面和游戏画面](./pro-jank-footy.avif)

这款游戏前不久在 Steam 正式发售了。我截图的时候看了一下，评价好像还不错？不支持 Mac，所以我暂时没买。

我还在一篇报道里看到，住在阿德莱德的韩国艺术家 [hyemina](https://hyemina.com/about) 也参与了制作，看到的时候特别开心。（我也是韩国人）

![hyemina studio 个性十足的作品](./hyemina-studio.avif)

感觉她做了很多有意思的东西。可爱，又很有个性。

总之，这个项目把我今天的 token 额度用完了。

![Codex 用量和可用的重置提示](./codex-usage.avif)

Codex 重置额度也太疯狂了吧。

对了，想的话也可以把球直接砸下去。
