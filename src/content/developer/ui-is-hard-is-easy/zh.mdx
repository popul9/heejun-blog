前阵子我发了一篇[《UI is Hard》](/zh/developer/ui-is-hard/)，有个朋友看完之后给我看了这个。

![Worst UI Challenge 的主页面和音量调节 UI 参赛作品](./worst-ui-challenge.avif)

听说这是一个做“最烂音量调节 UI”的[挑战](https://worst-ui-challenge.vercel.app/)。

听说还有一个单独的 [Reddit 频道](https://www.reddit.com/r/badUIbattles/)。

诶，好玩。我以前只会抱怨 UI 太难，从没想过故意把它做烂（至少最近没想过）。

嗯..我这个一直只追求效率、一路直行的脑子，这次就让它尽可能低效地转起来，像条倒着游的鱼一样，做一个低效的 UI 试试。

所以这篇文章算是上一篇的悖论，也是对 Richard P. Gabriel 的 [Worse is Better is Worse](https://dreamsongs.com/Files/worse-is-worse.pdf) 的致敬、献礼：**UI is Hard is Easy**。哈哈 😆。


## 核心想法

![橄榄球和同心圆目标点，中央标有音量 100%](./rugby-volume-target.avif)

把橄榄球踢出去，让它稳稳落进圈里。越接近目标点，音量就越接近 100。

我交给 Astra（Codex）去做，大概三十分钟，几轮提示词就搞定了。
拖动球再松手，就会踢出去。祝你踢得准..哈哈。

今天的主题是把 UX 搞砸？不过我的 UX 价值观照样适用。让用户对操作拥有控制权。
换个说法：你控制不了的部分可以有很多，但能控制的，我只给你一个。

## Inspiration

灵感来自今年年初我在游戏展上看到的 **Pro Jank Footy**。我之前在[这里](/zh/roamer/sage-2026/)分享过。

![Pro Jank Footy 的 Steam 页面和游戏画面](./pro-jank-footy.avif)
当时球的运动方式特别奇怪，我就问开发者是怎么做的。他说内部是 3D 引擎，玩家看到的则是蒙了一层 2D 滤镜。这件事在我脑子里转了好一阵，一直想着什么时候能用上，总算用上了..哈哈

这款游戏前不久在 Steam 正式发售了。我截图的时候看了一下，评价好像还不错？不支持 Mac，所以我暂时没买。

我还在一篇报道里看到，住在阿德莱德的韩国艺术家 [hyemina](https://hyemina.com/about) 也参与了制作，看到的时候特别开心。（我也是韩国人）

![hyemina studio 个性十足的作品](./hyemina-studio.avif)

感觉她做了很多有意思的作品。很有个性，又很可爱。


![Codex 用量和可用的重置提示](./codex-usage.avif)
总之，这个项目把我今天的 token 额度用完了。
Codex 重置的次数太多了。爱你。Astra 的 token 消耗 rate 就不爱了。

![瞄准后将球砸下的画面，带有 SPIKE 标识](./spike-kick.avif)

想的话，也可以把球直接砸下去。

![倒计时下玩耍的小狗](./puppy-play.avif)

啊对了，还可以和小狗一起玩。
