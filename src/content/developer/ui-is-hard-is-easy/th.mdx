เมื่อไม่นานมานี้ผมเขียนบทความ ['UI is Hard'](/th/developer/ui-is-hard/) แล้วเพื่อนคนหนึ่งอ่านเสร็จก็เอาของพวกนี้มาให้ดู

![ภาพหน้าหลักของ Worst UI Challenge และผลงานส่งประกวด UI ปรับระดับเสียง](./worst-ui-challenge.avif)

[Worst UI Challenge](https://worst-ui-challenge.vercel.app/)

ได้ยินว่ายังมี[ช่อง Reddit](https://www.reddit.com/r/badUIbattles/)แยกต่างหากด้วย

ได้ยินว่าเป็นชาเลนจ์ให้ทำ UI ปรับระดับเสียงที่แย่ที่สุด

ฮ่าๆ สนุกดีนะ ที่ผ่านมาผมคิดแต่จะบ่นว่า UI มันยาก ไม่เคยคิดจะทำให้มันพังโดยตั้งใจเลย (อย่างน้อยช่วงนี้ก็ไม่เคย)

อืม.. สมองของผมที่ไล่ตามแต่ประสิทธิภาพและพุ่งตรงไปข้างหน้ามาตลอด คราวนี้ลองให้มันทำงานอย่างไม่มีประสิทธิภาพที่สุดเท่าที่จะทำได้ เหมือนปลาที่ว่ายถอยหลัง แล้วลองทำ UI ที่ไม่มีประสิทธิภาพดู

บทความนี้เลยเป็นปฏิทรรศน์ของบทความก่อนหน้า และเป็นทั้งการคารวะและการอุทิศให้ [Worse is Better is Worse](https://dreamsongs.com/Files/worse-is-worse.pdf) ของ Richard P. Gabriel: **UI is Hard is Easy** ฮ่าๆ 😆


## ไอเดียหลัก

![ลูกรักบี้และเป้าหมายวงกลมซ้อนกัน โดยตรงกลางมีระดับเสียง 100%](./rugby-volume-target.avif)

เตะลูกรักบี้ให้ไปลงในวงกลมอย่างมั่นคง ยิ่งใกล้เป้าหมายมากเท่าไร ระดับเสียงก็ยิ่งใกล้ 100 มากเท่านั้น

ผมให้ Astra (Codex) ทำให้ ใช้เวลาประมาณสามสิบนาทีกับพรอมต์ไม่กี่ครั้งก็เสร็จ
ลากลูกบอลแล้วปล่อยมือ ก็จะเตะออกไป ขอให้เตะโดนนะ.. ฮ่าๆ

หัวข้อวันนี้คือการทำ UX ให้พัง? แต่แนวคิดเรื่อง UX ของผมยังใช้เหมือนเดิม ผมอยากให้ผู้ใช้ควบคุมสิ่งที่กำลังใช้งานได้
พูดอีกอย่างก็คือ ส่วนที่คุณควบคุมไม่ได้จะมีเยอะแค่ไหนก็ได้ แต่ส่วนที่ควบคุมได้ ผมให้แค่อย่างเดียว

## Inspiration

แรงบันดาลใจมาจาก **Pro Jank Footy** เกมที่ผมเห็นในงานเกมเอ็กซ์โปเมื่อต้นปีนี้ ผมเคยเล่าไว้[ที่นี่](/th/roamer/sage-2026/)

ตอนนั้นลูกบอลเคลื่อนที่แปลกมาก ผมเลยถามนักพัฒนาว่าทำยังไง เขาบอกว่าข้างในใช้เอนจิน 3D แต่สิ่งที่ผู้เล่นเห็นคือฟิลเตอร์ 2D ที่วางทับลงไป เรื่องนี้ติดอยู่ในหัวผมมาพักหนึ่งและคิดมาตลอดว่าจะเอามาใช้ตอนไหน ในที่สุดก็ได้ใช้แล้ว..ฮ่าๆ

![หน้า Steam และภาพในเกม Pro Jank Footy](./pro-jank-footy.avif)

เกมนี้เพิ่งวางจำหน่ายอย่างเป็นทางการบน Steam ตอนผมแคปหน้าจอ คะแนนรีวิวดูดีทีเดียว? เกมไม่รองรับ Mac ผมเลยยังไม่ได้ซื้อ

ผมยังอ่านเจอในบทความหนึ่งว่าศิลปินชาวเกาหลีที่อาศัยอยู่ในแอดิเลด [hyemina](https://hyemina.com/about) ก็มีส่วนร่วมทำเกมนี้ด้วย เห็นแล้วดีใจมาก (ผมก็เป็นคนเกาหลีเหมือนกัน)

![ผลงานที่มีเอกลักษณ์ของ hyemina studio](./hyemina-studio.avif)

ดูเหมือนเธอจะสร้างผลงานที่น่าสนใจไว้เยอะเลย มีเอกลักษณ์มากและน่ารักด้วย


![การใช้งาน Codex และตัวบอกเวลาที่รีเซ็ตได้](./codex-usage.avif)
ยังไงก็ตาม โปรเจกต์นี้ใช้โควตาโทเคนของผมวันนี้จนหมดแล้ว
Codex รีเซ็ตโควตาให้บ่อยเกินไปแล้ว รักนะ ส่วน rate การกินโทเคนของ Astra ไม่รักหรอก

![เล็งเพื่อฟาดลูกบอลลง พร้อมป้าย SPIKE](./spike-kick.avif)

ถ้าอยากก็ฟาดลูกบอลลงไปตรงๆ ได้เหมือนกัน

![น้องหมาวิ่งเล่นอยู่ใต้ตัวนับถอยหลัง](./puppy-play.avif)

อ้อ แล้วก็เล่นกับน้องหมาได้ด้วยนะ
